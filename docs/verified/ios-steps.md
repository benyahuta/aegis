# iPhone steps: verification against support.apple.com

Verified 2026-10-22 against Apple's iPhone User Guide for iOS 27 (the default) and iOS 26 (the `/26.0/` pages), the Apple Support articles and the Personal Safety guide. I compared exact menu wording from the page text. Nothing was checked on a device, so the P0 builder still has to confirm on hardware.

## Corrections (action needed)

1. **auto_updates (iOS):** iOS 26 and 27 have no toggle called "Security Responses & System Files". The Automatic Updates screen has *iOS Updates → Automatically Install* and *System Files → Automatically Install*.
2. **auto_updates (iOS), missing step:** since iOS 26.1, between-release security fixes are **Background Security Improvements**, at **Settings → Privacy & Security → Background Security Improvements → Automatically Install**. They are not under Software Update. Add this step.
3. **recovery_contact:** the menu is **Recovery Contacts**, not "Account Recovery" (iOS and Mac).
4. **stolen_device_protection, passcode_set, biometrics_enrolled:** Touch ID models (iPhone SE, Home-button models, and iPhone Duo in the iOS 27 guide) use **Touch ID & Passcode**. The SDP screen asks for the device passcode, and the options are *Away from Familiar Locations* / *Always*.
