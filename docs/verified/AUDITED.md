## 4. Refuted or over-claimed in the verification pass

1. **PayPal "do this in a web browser, not the app"** — not in PayPal's article; the article walks through the flow "on a mobile phone". Remove "(not the app)" from `service.paypal.step.2fa`.
2. **Venmo "all accounts already use multi-factor sign-in codes"** — not stated on the cited help pages (they say Venmo "may" send a code). Not in current copy; keep it out.
3. **T-Mobile SIM Protection under the "Manage" tab** — T-Mobile's guide says **Account** tab → gear → Security. Current copy says "Manage"; adjust as in §1 #4.
4. **Facebook Accounts Center URL "resolves"** — true in a browser (login redirect with `next=`), but it returns HTTP 400 to curl. Not a reason to change the URL; it is a reason to allowlist it in link-check.
